## 使用场景推荐

### 日常 Idea 交互与论文写作
- **主力模型**：Gemini-3-pro / Gemini-3-flash
- 这些模型在创意写作、内容生成方面表现出色

### 实验代码编写
- **主力模型**：Claude-4.5 系列
- **备选**：Cursor 内置的 Composer 模型

### 模型评价

从实际体验来看：
- GPT 5.1 与 GPT 5.2 的表现较为一般
- 目前对 GPT 系列模型的使用频率已大幅下降
- 建议优先尝试 Gemini 和 Claude 系列

## 注意事项

- 模型能力持续演进，建议定期查看最新的评测榜单
- 不同任务可能需要不同的模型，根据具体场景灵活选择
- 考虑成本、速度、质量三者的平衡
