# Prompt Taxonomy

Use these categories when storing local prompts:

- `coding`: implementation, debugging, refactoring, code generation
- `research`: research, comparison, synthesis, extraction
- `writing`: writing, editing, summarization, document production
- `review`: code review, QA review, evaluation, critique
- `translation`: translation, rewrite, localization
- `agent-control`: role prompts, delegation prompts, orchestration prompts
- `business`: PM, strategy, planning, business analysis

If a prompt clearly belongs to multiple categories, choose the primary usage context and add the others as tags in the prompt metadata.
