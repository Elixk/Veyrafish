# UI 二阶段功能保留决策矩阵

**状态**：已确认，按矩阵执行  
**日期**：2026-04-24  
**范围**：`templates/index.html`, `insight.html`, `media.html`, `query.html`, `forum.html`, `report.html`

---

## 1. 判定规则

| 建议 | 含义 |
|---|---|
| 必保 | 真实系统能力，移除会影响运行或演示闭环 |
| 保留但收纳 | 功能重要，但不应占据主视觉 |
| 演示态保留 | 视觉/讲解价值高，第一轮可用静态数据 |
| 延后 | 有价值，但当前系统数据链路不足或实现成本高 |
| 可移除 | 与当前演示目标弱相关，或已有替代入口 |

## 2. 全局功能

| 功能 | 当前位置 | 建议 | 理由 |
|---|---|---|---|
| 顶部导航六页跳转 | 所有模板 | 必保 | 演示和页面互通基础 |
| 系统配置弹窗 `.env` 双向同步 | 首页与各引擎页 | 必保 | API Key / provider 配置核心入口 |
| 保存配置 | 配置弹窗 | 必保 | 运行前置能力 |
| 保存并启动系统 | 配置弹窗 | 必保 | 当前端到端演示入口 |
| 刷新界面 | 系统菜单 | 保留但收纳 | 维护功能，低频使用 |
| 关闭系统 | 系统菜单 + 确认弹窗 | 保留但收纳 | 高风险操作，应低干扰且保留确认 |
| Socket 连接状态 | Header/Footer/Console | 必保 | 判断后端连接与实时日志是否正常 |
| 系统时间 | Footer | 保留但收纳 | 有演示氛围，但不是主功能 |
| 全局消息 toast | 所有模板 | 必保 | 操作反馈基础 |
| 控制台日志 | 所有引擎页 | 保留但收纳 | 调试/答辩有用，但不应压过主工作区 |
| 水墨背景、竹子、小舟、印章素材 | 新素材 | 必保 | 本轮视觉目标 |

## 9. 建议总表

| 类别 | 建议 |
|---|---|
| 必保 | 配置、启动、关闭、状态、Socket/SSE/轮询、iframe、Forum 消息、Report 生成导出、总览输入 |
| 保留但收纳 | 控制台日志、刷新、关闭、系统时间 |
| 演示态保留 | KPI、图表、矩阵、排行、热词、阵营、报告设置态 |
| 延后 | 地域热度真实接入、结果详情归档、核心用户画像、长图、润色/插图/引用证据真实编辑 |
| 可移除 | 暂无建议直接移除的真实功能；当前更适合“收纳”和“延后” |
