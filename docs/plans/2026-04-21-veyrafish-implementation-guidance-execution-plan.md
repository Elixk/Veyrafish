# Veyrafish 分阶段实施指导执行计划

日期：2026-04-21
运行模式：`/vibe`
内部执行等级：`L`

## 1. Strategy

将已有升级路线图转写为实施级文档体系，先建立统一治理框架，再拆分各阶段清单与日志规范。

## 2. Waves

### Wave 1：冻结本轮需求

- 明确本轮不是继续做架构分析，而是做实施手册
- 明确文档对象：总清单、阶段清单、日志模板

### Wave 2：设计总实施清单

- 统一阶段编号
- 定义阶段依赖和阶段门禁
- 明确跨阶段共通要求：测试、日志、回滚

### Wave 3：编写阶段实施清单

- Phase 0：工程治理
- Phase 1：运行架构升级
- Phase 2：Agent runtime 升级
- Phase 3：产品化与平台化增强

### Wave 4：编写日志规范

- 定义每轮任务日志字段
- 定义阶段日志目录和命名规则
- 定义阶段结束后的验收记录要求

### Wave 5：一致性复核

- 检查总清单与分阶段清单是否互相引用一致
- 检查所有阶段是否都包含测试与 bug 检查项

## 3. Ownership Boundaries

- 只新增文档
- 不修改现有实现
- 不引入新依赖

## 4. Verification

本轮通过以下方式验证：

- 文档文件是否全部成功创建
- 文档结构是否覆盖所有阶段
- 每个阶段是否包含任务、产出、测试、bug、日志要求

## 5. Cleanup Expectations

- 写入本轮 `vibe` 运行收据
- 不保留临时文件
