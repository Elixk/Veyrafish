# Veyrafish 前端功能清单

> 基于 `templates/index.html` 当前真实实现整理，不是理想状态图。

## 1. 当前前端的真实定位

当前首页不是纯产品首页，而是一个“单页控制台壳”，同时承担了：

- 查询输入
- 模板上传
- LLM 配置管理
- 三个引擎与论坛、报告的切换
- 控制台日志输出
- 论坛消息流展示
- 报告生成与下载
- 系统启动 / 关闭

这就是当前前端最大的结构问题：**产品操作、分析结果、系统运维被混在了一个页面层级里。**

## 2. 现有功能键总表

## 2.1 顶部输入区

### 查询相关

- `搜索输入框`
- `开始`

当前作用：

- 发起整套分析流程

保留建议：

重构建议：

- 首页主输入区保留，但视觉上升级为“主题分析输入”

### 模板相关

- `上传模板`

当前作用：

- 上传自定义报告模板

保留建议：

- 收纳为“高级选项”或“报告偏好”入口

### 配置相关

- `LLM 配置`

当前作用：

- 打开配置弹窗

- 从首页主操作区迁出，放入右上角系统工具区或系统抽屉

## 2.2 全局系统操作

- `关闭系统`

重构建议：

## 3. 功能优先级分层

## P0 必须保留

- 分析输入
- 五个引擎导航
- 报告生成与下载
- 任务状态与日志可见性
- 系统配置入口

## P1 应迁移但保留

- 模板上传
- 论坛消息流
- 控制台输出
- 系统启动状态展示

## P2 不应先做重设计

- 复杂动态水墨交互
- 大量装饰性动画
- 高成本书法字体混排特效
- 所有内页一次性高保真实现

## 4. 当前最该解决的问题

1. 同一页面同时承担“产品首页”和“系统控制台”职责。
2. 五个引擎虽然已经存在，但在信息架构上仍然只是标签切换，不是真正页面。
3. 首页主按钮区混入了管理员操作。
4. 视觉层级与功能层级不匹配，导致页面看起来像开发面板，不像产品入口。
