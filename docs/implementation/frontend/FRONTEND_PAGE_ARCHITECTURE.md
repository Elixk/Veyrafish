# Veyrafish 前端页面信息架构

## 1. 页面总原则

- 首页负责总览与起始操作
- 引擎页负责专项分析与细节操作
- 系统配置与运维控制从业务页面中抽离
- 先保证结构正确，再逐步贴近国风高保真视觉

## 2. 顶层页面结构

建议的顶层导航：

- `总览`
- `洞察`
- `媒析`
- `检索`
- `论坛`
- `报告`

右上角工具区：

- `系统配置`
- `任务中心`
- `系统状态`
- `管理员操作`

## 3. 首页：总览

## 3.1 首页职责

- 输入分析主题
- 查看全局任务状态
- 查看五引擎摘要
- 快速进入各引擎页
- 查看最近报告与最近任务

## 3.2 首页应包含的模块

### A. 顶部品牌区

- 平台标题
- 一句古雅副标
- 顶层导航

### B. 主输入区

- 分析主题输入框
- 开始分析按钮
- 高级选项入口

高级选项中包含：

- 模板上传
- 时间范围
- 深度级别
- 数据范围

### C. 总览面板

- 本次任务总体状态
- 最近一次数据更新时间
- 五引擎摘要卡片

### D. 五引擎入口区

- Insight 卡
- Media 卡
- Query 卡
- Forum 卡
- Report 卡

### E. 最近产物区

- 最近报告
- 最近任务
- 最近异常

## 4. 洞察页：Insight

## 4.1 页面职责

- 展示总体态势、情感分布、风险异动、热点演进

## 4.2 页面结构

- 左侧：维度切换与筛选
- 中部：趋势图 / 风险图 / 时间线
- 右侧：洞察摘要与建议动作

## 5. 媒析页：Media

## 5.1 页面职责

- 展示媒体传播路径、来源分布、媒体立场

## 5.2 页面结构

- 左侧：媒体源筛选
- 中部：传播图和媒体内容卡
- 右侧：传播诊断与重点媒体

## 6. 检索页：Query

## 6.1 页面职责

- 承担高级搜索、结果筛选、证据查看

## 6.2 页面结构

- 顶部：强搜索区
- 中部左侧：结果列表
- 中部右侧：详情预览与证据操作

## 7. 论坛页：Forum

## 7.1 页面职责

- 展示 Agent 协作、主持人引导、讨论焦点

## 7.2 页面结构

- 左侧：回合 / 阵营 / 焦点筛选
- 中部：讨论流与焦点图
- 右侧：论坛研判摘要

## 8. 报告页：Report

## 8.1 页面职责

- 预览报告
- 生成报告
- 导出 HTML/PDF/MD
- 查看报告结构与定稿状态

## 8.2 页面结构

- 左侧：结构树与报告设置
- 中部：报告预览区
- 右侧：导出、定稿和快捷操作

## 9. 系统控制层

以下功能不应继续占据业务首页主视觉：

- LLM 配置
- 保存并启动系统
- 关闭系统
- 开发调试输出

建议放到：

- 右上角系统抽屉
- 管理员模式
- 独立系统状态面板

## 10. 实现上的降级策略

## 第一层：结构优先

- 先完成页面拆分、导航、模块边界、状态流

## 第二层：视觉升级

- 再引入国风排版、配色、边框、纸纹、印章

## 第三层：高级视觉

- 最后才加复杂水墨动画、动态山水背景、重书法特效

原因：

- 这些高级效果对结构没有帮助
- 先做会显著增加开发难度和后续维护成本
